

# Explorer Docks

Windows標準のエクスプローラーを画面端に収納できる軽量アプリです。必要なときだけ展開して使えます。

## ダウンロード

[最新版をダウンロード](https://github.com/mayomayowyi/Explorer-Docks/releases/latest)

Windows 11 / x64

## 使い方

> **※ ご注意：** 以下の動画は旧バージョンの操作例です。v0.0.4以降は「Works」などの機能が追加されているため、現在の画面や操作方法とは一部異なります。

https://github.com/user-attachments/assets/7e214848-f30d-4ac9-b2d6-79e98b083c10
<!-- ここに Explorer Docks2.mp4 をドラッグ＆ドロップすると、動画が表示されます。 -->

1. エクスプローラーの右上にある「Dock」をクリックすると、画面端へ収納されます。
2. 画面端のハンドルにカーソルを合わせると展開できます。
3. ハンドルをクリックすると収納・展開を切り替えられます。
4. 自動収納の時間やアニメーションは、タスクトレイから変更できます。

v0.0.4以降は複数のエクスプローラーをDock化し、「Works」でまとめて管理できます。
